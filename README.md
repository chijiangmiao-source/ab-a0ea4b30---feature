# 低温磁阱电流安全审计（coil-audit）

在调整多个线圈电流前，确认安全约束、电源约束与场强线性上界能否**同时**满足。
系统对用户录入的整数不等式 `a·x ≤ b` 给出可复核的精确结论：

* **可行** → 由固定枢轴规则（Bland 规则）得到的一组**有理电流**，以及每条约束的
  **精确余量** `b − a·x`（分数形式，无浮点误差）；
* **无解** → 非负有理 Farkas 乘子，使各约束左侧系数逐项相加为零、右侧和严格为负，
  合并出矛盾式 `0 ≤ -k`，并逐项展示加权合并过程。

核心算法是**任意精度有理数 Phase-I 单纯形**（Python `fractions.Fraction`），
不使用浮点、采样、外部线性规划服务，也不会在无解时只报告“无解”而不给证据。

## 运行包线（扰动投影）

读取一条**已可行**审计后，工程师可为**每条原约束**填写两个**整数**扰动系数
`(p_i, q_i)`（功率漂移 `u`、场强偏置 `v`），共同变化后的系统为

```
a_i·x + p_i·u + q_i·v ≤ b_i
```

系统以**任意精度有理数 Fourier–Motzkin 消元**逐个消去电流变量 `x`，
把全部可行扰动对**精确投影**到 `(u, v)` 平面（不抽样、不浮点、不只检查两个扰动轴）：

* 创建成功后页面展示**规范化有理二维半平面**（`α·u + β·v ≤ B`，
  `α,β,B` 互素整数）及每条边界的**来源合并式**（非负有理乘子 λ，
  逐项可见 `Σλ·a=0`、`Σλ·(p,q)=(α,β)`、`Σλ·b=B`）；
* 输入**包线内的有理坐标**（如 `"1/2"`）→ 显示“可行”，并给出一组
  **可复算电流**与逐约束精确回代余量；
* 输入**包线外坐标** → 稳定标出**首条违约边界**、**严格违反值**
  （左端 − 右端 > 0）与代入结果；恰落在边界上（余量为 0）判可行；
* 比例重复边界只保留一条，同方向平行边界只保留最紧右端，全零系数行
  （`0 ≤ B`）按重言式丢弃；零扰动 ⇒ 空边界集合表示**整个平面**，
  无界方向通过回收锥精确判定并给见证方向，**绝不错误封闭**；
* 来源不存在、来源不可行、扰动对数与原约束不符、系数非整数、
  或 Fourier–Motzkin 中间膨胀超过受理规模（1024 行）一律拒绝（不落盘）；
  复用包线编号却改变来源或系数返回 **409**，原审计与已冻结包线均不可改写。


## 运行

```bash
# 宿主机端口可配置（默认 8080）
HOST_PORT=9090 docker compose up --build
# 浏览器打开 http://localhost:9090
```

健康状态：`GET /healthz` → `{"status":"ok",...}`（Compose 以该端点作为
服务健康条件）。冻结记录持久化在命名卷 `audit-data` 中。

### verify 单次容器

```bash
make verify          # = docker compose build
                     #   && docker compose up --abort-on-container-exit \
                     #                      --exit-code-from verify
echo $?              # 0 表示全部通过
```

`verify` 容器（`restart: "no"`）在 web 健康后运行一次并退出：

1. 容器内执行全部代码测试（pytest）；
2. HTTP 冒烟：健康检查、首页（含包线入口）、未知审计/包线编号返回 404；
3. 用两组“相加得 `0 ≤ -1`”的约束（`0·x ≤ -1`；`x ≤ 0` 与 `-x ≤ -1`）
   经真实 HTTP 提交，独立重算并核对 `μ ≥ 0`、`Σμ·a = 0`、`Σμ·b = -1`，
   同时核对幂等重放（200，同一记录）与改动载荷冲突（409，原证据不变）；
4. 再提交一个可行系统核对有理解与余量；
5. 经真实 HTTP 创建一个有界三角形包线，独立重算每条规范化边界的来源合并式，
   核对幂等（200）、改系数/改来源的 409 保护、来源不存在/不可行/对数不符/
   非整数/非法有理/规模超限（400/404/422）拒绝，再对**创建与坐标查询接口**
   冒烟：内点给可复算电流（独立回代）、边界点余量为 0、外点首违与严格违反值。

任一步失败即以非零码退出；全部通过输出 `VERIFY OK` 并以 **0** 退出。
镜像构建本身由 `make verify` 的 `docker compose build` 完成，失败同样中止。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/audits` | 提交审计（JSON 见下） |
| `GET`  | `/api/audits/{audit_id}` | 按编号重新读取冻结结果 |
| `POST` | `/api/envelopes` | 在可行审计上创建冻结运行包线 |
| `GET`  | `/api/envelopes/{envelope_id}` | 读取冻结包线（规范化边界与来源合并式） |
| `POST` | `/api/envelopes/{envelope_id}/query` | 有理坐标查询：可行电流或首条违约 |
| `GET`  | `/healthz` | 健康检查 |

创建包线载荷（`perturbations` 每元素两个整数，长度须等于原约束条数）：

```json
{
  "envelope_id": "trap-run-A-envelope",
  "source_audit_id": "trap-run-2026-09-28-A",
  "perturbations": [[1, 0], [0, -1]]
}
```

* 首次 → `201`，完全相同载荷重传 → `200`（同一冻结记录）；
  改来源或任一扰动系数 → `409`；来源不存在/不可行/对数不符/非整数 → `400`；
  投影中间膨胀超过受理规模（1024 行）→ `422`（不写入）。
* 坐标查询：`{"u":"1/2","v":"-3"}`（也接受 JSON 整数，拒绝浮点与分母零）。
  内点返回 `status:"feasible"` + `currents` + `residuals` + 逐边界 `boundary_checks`；
  外点返回 `status:"infeasible"` + `first_violation`（首条违约边界、严格违反值
  `gap`、代入式），恰落在边界上判可行。

提交载荷（1–8 个变量，1–48 条约束；系数与右端必须是 **JSON 整数**，
`1.0`、`true`、`"3"` 一律拒绝）：

```json
{
  "audit_id": "trap-run-2026-09-28-A",
  "variables": ["I1", "I2"],
  "constraints": [
    {"coeffs": [1, 1], "b": 40, "label": "电源总电流上限", "stable": true},
    {"coeffs": [2, -1], "b": 10, "label": "场强线性上界", "stable": false}
  ]
}
```

* 首次提交 → `201`，结论与载荷指纹一起冻结落盘；
* 相同编号 + **完全相同载荷**重传 → `200`，返回同一条冻结记录（含相同
  `created_at` 与 `fingerprint`）；
* 相同编号 + **改动过的载荷**（任何系数/右端/标签/稳定标识/变量名变化）
  → `409 Conflict`，响应给出新旧指纹，**原证据不变**；
* 非法载荷 → `400`，不求解、不写入，任何旧结论都不会残留或被覆盖。

无解响应示例（节选）：

```json
{
  "result": {
    "status": "infeasible",
    "multipliers": [{"index": 0, "value": "1"}],
    "terms": [{
      "index": 0, "b": "-1", "multiplier": "1",
      "weighted_coeffs": ["0"], "weighted_rhs": "-1"
    }],
    "combined_lhs": ["0"],
    "combined_rhs": "-1",
    "combined_relation": "0 <= -1"
  }
}
```

## 实现说明

* `app/simplex.py` — 有理数 Phase-I 单纯形：
  自由变量统一拆成 `u − v`；右端为负的行先整体乘 `-1`（记 `σ = sign(b)`，
  对应松弛/剩余变量系数同为 `σ`），加入人工变量得到对任意整数右端都合法的初始基；
  最小化人工变量之和，按 **Bland 固定枢轴规则**（编号最小的负约化成本列入基，
  最小比值、并列时基变量编号最小者出基；人工列永不重新入基）防止退化循环。
  终表目标行松弛/剩余列的约化成本即 Farkas 乘子，代码对 `μ ≥ 0`、
  `μᵀA = 0`、`μᵀb = −w* < 0` 做运行时断言。
* `app/models.py` — 审计整数级输入校验（拒绝浮点/布尔/字符串数字、超大整数）。
* `app/envelope.py` — 精确二维投影：有理数 Fourier–Motzkin 消去电流变量，
  每行正向整数规范化（乘公分母、除 gcd，**绝不乘 -1** 以免反向）并按键去重；
  同方向平行边界取最紧右端；每条边界保留非负有理来源乘子并运行时断言
  `Σλ·a=0`、`Σλ·(p,q)=(α,β)`、`Σλ·b=B`；无界性以回收锥（复用精确单纯形）
  判定并给见证方向；内点查询把固定点代入右端化为整数行再求可复算电流。
* `app/envelope_models.py` — 包线请求（两个整数扰动系数/约束）与有理坐标校验。
* `app/storage.py` — 审计与包线冻结存储：每编号一个 JSON（包线加 `env-` 前缀
  并以独立命名空间哈希），临时文件 + fsync + 原子 rename，进程内锁串行化
  “检查-写入”；包线指纹含**来源审计指纹**，故改来源/系数必然 409。
* `app/web.py` — 仅依赖 Python 标准库的 HTTP 服务；`app/static/index.html`
  为浏览器页面（整数以文本正则校验后直接拼装 JSON，避免 JS `number` 丢精度；
  坐标以有理文本提交）。
* `tests/` — 209 个测试；其中 `tests/fourier_motzkin.py` 用与单纯形完全不同的
  Fourier–Motzkin 消元对大量随机/枚举小系统做交叉判定，并独立核验证书；
  包线测试用同一独立 FM 对随机系统与随机有理点交叉验证投影成员关系。
